# Gaurav Mangal — Personal Portfolio

A minimalistic, responsive personal portfolio website built using **HTML, CSS, and JavaScript**.

The website showcases my background as a Software Engineer, including my skills, professional experience, education, selected projects, and contact information.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

No frameworks, libraries, build tools, or backend services are required.

## Sections

- **Home** — Introduction and professional highlights
- **Skills** — Programming languages, web/backend, cloud/DevOps, and AI/ML skills
- **Experience** — Professional and academic experience
- **Education** — Academic background
- **Projects** — Selected technical projects
- **Contact** — Email, phone, LinkedIn, and GitHub

## Features

- Minimalistic dark design
- Responsive layout for desktop and mobile
- Smooth scrolling navigation
- Active navigation state based on the current section
- Subtle hover and entrance animations
- Clickable contact and social links
- No external build process required
